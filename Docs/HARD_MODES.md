# ノーマル／ハードとステージ3の可動柵撤去

実装済みのステージ1〜3にハードを追加しました。年表のステージ詳細で「ノーマル・切替」を押すと「ハード・切替」に変わります。攻略説明・難易度表示・攻略済み表示が選択モードに切り替わり、「挑戦」で対応するステージへ進みます。リトライは同じモードのままです。プレイ中の左上タイトルにはハードのみ「（難）」が付きます。

解放済みステージでは最初から両モードを選択できます。直前のステージをどちらかのモードでクリアすると次が解放されます。ノードのクリア印はどちらかをクリアした印、詳細の攻略状況は選択中のモードの記録です。

| ステージ | ノーマル | ハード |
| --- | --- | --- |
| 1 落石の山道 | 風3・雷2。落石予告6秒／13秒、落下0.6秒、危険半径0.7 | 風2・雷1。信長が近づくと予告1秒→落下0.45秒、危険半径0.85。岩は遠くで待っていても落ちないため、雷を使う岩と風で回避する岩を選ぶ |
| 2 忍び寄る凶刃 | 風3・幽霊2。後方から暗殺者1人。幽霊への影響倍率を0から1へ修正 | 風2・幽霊2。後方に加え前方に青い暗殺者。青い敵は風無効・幽霊有効。誘導は6秒。幽霊に信長を巻き込まない脇道と配置タイミングを選ぶ |
| 3 炎上する宿場 | 風3・雷2・雨2。本通りに火災2か所 | 風2・雷1・雨1。裏道にも独立した火災1か所。本通りの2か所を雨1回では同時に消せないため、柵を開けて裏道を使う／風で火災を回避する計画が必要 |


制限時間はノーマル45秒、ハード40秒。落石の位置は両モードとも固定です。ステージ3の動く柵と付属のObstacle Colliderは両モードから削除しました。雷で燃やす固定柵、風で信長を上の道へ誘導する処理、右上のゴールは維持しています。裏道の追加火災は固定柵から独立しているため、観察中に柵が勝手に燃え尽きることはありません。

## 保存とアセット

- 既存の `StageCleared_1` などはノーマル記録として維持。ハードは `StageCleared_1_Hard` など別キーで保存します。
- `GameSession.SelectedDifficulty` に選択モードを保持し、GameSceneのStageLoaderが対応Prefabを生成します。
- 新規Prefabは `Assets/Project/Prefabs/Stage/Stage_01_Hard.prefab`、`Stage_02_Hard.prefab`、`Stage_03_Hard.prefab`。既存ステージを複製して難易度だけ調整しています。今後共通UIや配置を編集するときは通常版とハード版の両方へ反映してください。
- 既存.meta・GUID・画像・シーン参照は維持。新規Prefabにのみ新しい.metaを追加しています。Inspectorへの追加接続は済んでいます。

Unity Editor・C#コンパイル・試遊はこの環境では未実施です。ハードの強さは初期調整値で、実際のクリア難度は試遊で確認が必要です。モード別Prefab選択と既存クリア記録の互換・分離を検査するPlayModeテストも追加しましたが、実行は未実施です。

1. 年表で各ステージの詳細を開き、「ノーマル・切替」を押してハードへ変更。説明と攻略状況が切り替わり、文字が重ならないことを確認。
2. 挑戦後、左上の「（難）」、40秒、能力回数を確認。ポーズ・失敗・クリア後にリトライし、同じハード条件と能力回数へ戻ることを確認。

GameSceneを直接テストする場合はSceneNavigationではなくStageLoaderコンポーネントの `Use Editor Test Stage` をオンにし、`Editor Test Stage Id` と `Editor Test Difficulty` を指定してください。年表から選ぶときはオフに戻してください。

## 幽霊と攻略手順の見直し

ステージ2ではDivinePowerReceiver2Dの `influence.ghost` が0になっており、暗殺者側の判定で幽霊が無視されていました。ノーマル・ハード両方で1へ修正しました。ハードの前方の青い暗殺者も幽霊の対象です。風に対しては前方だけ0、後方は1です。後方の速さはノーマルと同じ1.05へ戻し、前方は0.9、攻撃予告は双方1.1秒としています。速さだけではなく、相手と誘導先の選択を考える構成です。

ハード1の岩の接近条件はProtectedTarget2DのColliderが半径2に入ることです。最初の接近後は離れても予告を取り消しません。離れた場所からの雷でも落下します。リトライで接近待ちへ復元し、ノーマルは以前の時間式を維持しています。

追加検査：幽霊の受信倍率、青い敵の通行可能な初期位置、雨1回では本通り2か所を同時に覆えない距離、接近式落石の保存設定、文字収録、参照・C#構文を検査しました。幽霊で攻撃を中断して移動する処理と、岩の接近待ち・雷・リトライを対象にPlayModeテストを追加しましたが、Unityでの実行は未実施です。攻略成立・操作感・難易度の最終確認には試遊が必要です。

## 攻略のブラッシュアップ：待ち伏せを誘い出す

ハード2の青い暗殺者を、開始から2秒で追跡する設定から「距離3以内かつ障害物に遮られていない接近で追跡」に変更しました。待機中も到達可能な幽霊に反応し、先に脇道へ誘い出せます。一度追跡を始めると幽霊が消えても待機には戻らず、リトライで初期位置・待機状態へ戻ります。攻撃の予告時間1.1秒、移動速度、風無効、能力回数は従来どおりです。後方の敵とノーマルは従来の追跡方式です。

対象：`Stage_02_Hard / World / FrontAssassin_WindImmune` の `AssassinChaser2D`。`Ambush Distance = 3`、`Start Delay = 0` をPrefabへ設定済みです。`Ambush Distance = 0` は従来の動作を維持します。

攻略の狙いは、後方の追手を風で離してから前方を誘うか、先に前方を脇道へ誘い出して通過の機会を作るかを選ぶことです。双方の攻略成立と難しさは実機試遊で評価してください。ハード1・3は今回配置や強さを変えず、年表説明を制約中心に整理しました。ハード3の説明から、裏道を使う手順の断定を除いて自分で経路を考えられる内容にしました。

クラウドではPrefab設定・参照、文字収録、経路の静的検査とC#構文解析を実施。PlayModeテストに「遠方で待機」「接近／幽霊による開始」「ポーズ中に開始しない」「誘導終了後も追跡」「リトライで待機へ戻る」を追加していますが、Unityでの実行は未実施です。

Unityでの確認：
1. 年表からステージ2のハードを開始。青い敵が遠方で待機し、後方の敵だけが追いかけること。
2. 上下の脇道に幽霊を置き、青い敵を誘い出す。信長を巻き込む配置と、敵だけを誘う配置の違いを確認。
3. 幽霊を使わず接近しても青い敵が追跡を開始し、斬撃予告が出ること。
4. 誘導中のポーズ・再開、失敗後のリトライで位置や状態が残らないこと。
5. 風を後方に残す攻略と、信長を前へ押す攻略をそれぞれ試し、最も忙しい場面が反射神経だけに偏っていないか確認。
