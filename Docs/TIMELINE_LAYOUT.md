# 年表画面と第一幕の表示修正

第一幕を「落石の山道」に改名しました。年表の表示名と詳細説明は `Assets/Project/Data/Stages/StageData_01.asset`、プレイ中の左上表示は `Assets/Project/Prefabs/Stage/Stage_01.prefab` のCanvas / GameUI / HUD配下のStageTitle・StageHintです。タイトルとヒントの書式・位置は第二幕、第三幕と同じです。

`Assets/Project/Scenes/TimelineScene.unity` の修正内容：

- 詳細の説明欄が200×50で長文が溢れていたため、720×160へ拡張。名前、年号、難易度、攻略状況、説明、ボタンの領域を分離。
- 白い和紙パネルに白文字だった情報欄を墨色に変更。
- Canvasを1280×720基準・高さに合わせる拡大縮小に変更。900×600の詳細ウィンドウが横画面の4:3、16:9、21:9に収まる構成。
- ステージ名と年号の重なっていたRectTransformを独立した大きさへ変更。共有Stage01Button Prefabを変更し、3ステージとも反映。
- クリア印がノードより大きかったため、ロック印と同じ150×150へ統一。
- 年表の線をノード間に配置し、ノードを同じ高さに揃えた。Contentの幅は3200から1500へ変更し、3ステージの後に残っていた空白を削減。
- 使用フォントに★と☆がないため、難易度は「難易度 1 / 5」形式に変更。
- 情報テキストのRaycastを解除。ウィンドウ本体と外側の閉じる領域の入力判定は維持。

画像、.meta、GUID、Inspectorの参照、ステージ解放条件を維持しています。追加のInspector設定は不要です。

## 検証

クラウドで実行済み：Scene／PrefabのYAML、fileID・親子関係・追加参照、C#構文、情報欄の矩形同士の重なり、横画面の画面内配置、文言のフォント収録、カメラ・音の重複設定、第一幕の経路検査。説明文の行数は保守的な文字数計算で確認しており、TextMeshProの実描画ではありません。

2. 解放済みのステージで詳細を開く。長い説明も収まり、難易度・攻略状況・挑戦／戻るボタンが読み取れること。
