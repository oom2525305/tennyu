# ステージ1〜3：操作感と既存機能の精査

## 見つかった原因と修正

| 対象 | 修正 |
| --- | --- |
| 風の方向指定 | 実コードは上下左右の4方向へ丸めていました。斜めを含む自由な方向へ変更し、矢印も実際の方向へ回転。方向確定の移動量を55から35 Canvas単位へ減らし、解像度に合わせて換算します。 |
| 風と自動歩行の競合 | 風の最中にも自動歩行が元の進路へ戻そうとしていました。勢いが残る間は風を優先し、終了位置から改めて探索します。 |
| 壁への引っかかり | 最初の壁に当たると斜め移動全体を止めていました。移動を壁の手前まで進め、残りを壁沿いへ投影して再度形状Castします。最大3回の確認で角抜けを防ぎます。信長と暗殺者に適用。可動柵は信長を押し潰さない従来の停止処理を維持。 |
| 経路の作り直し | 通れる経路も0.25〜0.5秒ごとにA*で作り直していました。現在位置から残り全区間の通行可否を定期確認し、障害物で塞がれた場合などにだけ再探索。風の終了や誘導対象の変更でも再探索します。 |
| 細かい格子点 | A*の結果を体の形で直線確認し、不要な中間点を除去。経由地点に着くたび1フレーム止まる処理も修正しました。 |
| ステージ1のゴール前 | 元の壁までの距離0.42056に対し、体と余裕で必要な距離は0.42。最終区間の壁を調整し、約0.569まで広げました。 |
| ステージ1の雷 | 落石に能力受信Componentがなく、雷ボタンが攻略につながっていませんでした。予告位置のAbilityTargetへ受信Colliderを追加。雷で早く落とせます。着地点は固定し、風では動きません。着地済みの岩への受信は無効化し、リトライで復元。 |
| 落石の表示 | 予告・影・カウント表示を固定の着地点に揃え、落下開始でカウントを隠します。カウント文字のRaycastを無効化し、入力を邪魔しない設定にしました。 |
| ステージ2の暗殺者 | 信長が直線で見えるときはグリッド探索せず追跡。遮蔽物の迂回探索は0.6秒間隔。壁沿いの移動も共通処理へ変更。 |
| ステージ3の分岐 | 宿の左の分岐入口と上へ曲がる区間を拡張。差し替え画像・画像.metaは変更していません。 |
| 制限時間 | ドラッグ中、移動は1/3速なのに制限時間だけ通常速度でした。StageTimeの同じ時間で減らすよう統一。 |
| ゴール・時間切れ | ステージ1も時間切れは失敗に統一。ゴールはPlaying中のみ有効。開始前に重なっていた場合はPlayingになってから判定します。 |
| ドラッグ終了 | Playingでなくなったときや発動範囲外で離した場合はキャンセル。使用回数を消費しません。 |

既存の.meta・Component名・失敗Spriteの復元仕様を維持しています。ハード難易度やステージ4〜5の追加は行っていません。

## 手動確認

GameSceneのStageLoaderで **Use Editor Test Stage = オン**、**Editor Test Stage Id = 1、2、3** を順番に指定します。確認後はオフへ戻してください。

- **共通**：風を斜めに指定。壁へ斜めに押した際の動き、経由地点の停止、制限時間のスローを確認。風の指定は「場所で短く止める → 出た矢印を動かす → 離す」です。
- **ステージ1**：落石の予告位置へ雷を落とすと早く落下。風では予告位置も着地点も移動しません。信長を雷の範囲に巻き込むと失敗する点に注意。ゴール前で引っかからないか確認。
- **ステージ2**：追跡、赤い攻撃予告、風で中断、幽霊で誘導、失敗とリトライ。暗殺者の速度・猶予は実機で再調整が必要な可能性があります。
- **ステージ3**：上の固定柵を雷で開通し、宿の左の分岐で信長を上〜右上へ押す。押した後に元の道へ強く引き戻されず、上の道へ進むか確認。可動柵で本通りの先を塞いだ場合、先まで歩いてからではなく、残り経路の検査で迂回するかも確認。
- **各ステージ**：操作中のポーズ、再開、リトライ、失敗Spriteの維持、クリアから年表へ戻る、音の残留を確認。

なお、動きが改善しない場合はUnity ProfilerでCPU使用量とPhysics 2Dを確認する必要があります。今回のクラウド検査から実機のフレーム時間は判断できません。


## UI統一と落石位置の固定（追加修正）

- Stage_01〜03のCanvasScalerをステージ1のConstant Pixel Size・Scale Factor 1へ統一。タイマーは300×80／文字52、開始ボタンは400×150、能力ボタンは130×130。能力の並び位置、能力を置ける画面領域も共通化しました。
