# 音量設定と第四幕「崩れ橋の渓谷」

## 追加した内容

Title、TimelineScene、全ステージの右上（ポーズボタンの左）に「設定」を追加。BGMとSEを個別に0〜100%へ調整できます。「音を試す」は現在のSE音量で既存のボタン音を再生します。0%は消音。初期値100%はこれまでInspectorで調整した音量をそのまま使う値です。

変更は再生中の音へ即反映し、「閉じる」、フォーカス喪失、シーン終了時にPlayerPrefsへ保存します。キーは `Tenyu.Audio.Music` / `Tenyu.Audio.Effects`。クリア記録には触れません。設定中に音を再起動したり、BGM用Audioをシーン間で永続化したりはしません。

プレイ中に開くと一時停止し、設定から閉じたときだけ再開します。もともとポーズしていた場合は閉じてもポーズのままです。観察中・クリア・失敗画面から開いてもフェーズを変えません。ドラッグ中は設定ボタンを無効にします。設定の前面パネルが背面へのタップを遮り、キーボード／ゲームパッドの選択もパネル内に留めます。

## Unity内の配置

- `Title / Audio`、`TimelineScene / Audio`、`Stage_01`〜`Stage_04_Hard` の `Systems / Audio`：`TenyuSettingsUI` を接続済み。
- Inspectorの `Stage Director`（タイトル・年表は空）、`Scene Audio`、`Font`、`Panel Sprite`、`Button Sprite` は設定済みです。
- 再生時にそのAudio配下へ `SettingsCanvas / 設定` と `SettingsOverlay / SettingsPanel` を生成。1280×720・高さ基準、パネル760×480。Camera・EventSystem・AudioListenerは生成しません。
- BGM、ボタン／開始／結果／能力音は `TenyuSceneAudio`、雨／炎は `TenyuEffectLoopSound`、既存の落石・敵のAudioSourceは `TenyuStageSourceGuard` 経由でSE設定を反映。

## ステージ4

年表のステージ3の右側へ第四幕を追加しました。ステージ3をどちらかの難易度でクリアすると解放。`GameScene / StageLoader` のID 4にノーマル・ハード両方を登録済みです。年表の難易度切替・クリア記録・リトライは既存の仕組みを使います。表示年は1567年（架空の出来事の時代目安）です。

**専用背景は未提供のため、ステージ1の山道背景・通行範囲を使った試作版です。** 崩れる橋の板・縄・谷部分を簡易表示しています。専用の渓谷画像が入った段階で、背景に合わせて橋・道・障害物・ゴールを配置し直す必要があります。土壁・対象の時間停止は今回導入していません。

| 内容 | ノーマル | ハード |
| --- | --- | --- |
| 能力 | 風3・雷2 | 風3・雷1 |
| 制限時間 | 45秒 | 40秒 |
| 橋 | 2か所、踏んでから3.6秒で崩落 | 同じ2か所、1.9秒で崩落 |
| 岩 | 接近で2.2秒予告 | 接近で1.2秒予告 |

橋は観察中には壊れず、信長のColliderが重なると秒読みを開始。離れても秒読みは続きます。崩落した橋に信長が残っている、または再び入ると失敗。ポーズ／能力操作中のスローはStageTimeに従い、リトライで板・秒読み・位置を復元します。橋は風で動かず、信長を押して渡します。雷は既存の落石を早く落とす用途です。

`Stage_04(.prefab / _Hard.prefab) / World / Route / CollapsingBridge_1・2` の `CollapsingBridge2D`：`Collapse Delay` が崩落までの時間、`Size` が危険区域です。専用Material・フォントも接続済み。橋の表示は再生時に生成します。

通常移動で橋を横切る時間の概算は2.4秒（橋1.6＋信長直径0.8、移動速度1）。ハードは風で短縮する想定です。これは直線の概算であり、実際の入力タイミング・物理処理・攻略成立を保証する試遊結果ではありません。

## 検証

クラウドで実行：既存1〜3の静的経路検査、`validate_hard_modes.py`、`validate_settings_stage04.py`、C#構文解析。参照・ID・親子関係、設定の10か所への接続、4の通行幅、橋と経路の重なり、年表登録、使用文字のフォント収録を検査しました。

Unity Editor、C#／Shaderのコンパイル、PlayModeテスト、画面表示、音の試聴、難易度試遊は未実施です。PlayModeテストには橋の観察／ポーズ／崩落／退避／リトライ、音量の即時反映と倍率の重複防止を追加しました。

## Pull後に確認する手順

1. Unityのインポート完了後、ConsoleでC#・Shaderエラーがないことを確認。
2. Title右上の「設定」でBGMを0%、SEを50%へ変更し、「音を試す」。年表へ移動して値が維持され、Unity再起動後も残ることを確認。
3. ステージ3で雨・炎・能力音、ステージ1で落石を確認。ポーズ中に音量を変えても環境音が勝手に再開しないことを確認。
4. プレイ中／ポーズ中／観察中／クリア・失敗中から設定を開閉し、意図しない再開や背面ボタンへの入力がないことを確認。
5. 年表の一番右で第四幕を選択。未解放ならステージ3をクリアするか、GameSceneのStageLoaderで `Use Editor Test Stage` をオン、`Editor Test Stage Id = 4` と難易度を指定してテスト。年表から遊ぶ前にテスト設定をオフに戻す。
6. 第四幕の両モードで橋の秒読み・風での退避・崩落時の失敗・ゴール・リトライを確認。ハードは風を2つの橋へ配分し、残りの風と雷で落石を避ける手順を試す。
7. Test RunnerのPlayModeで `GameplayRegressionTests` を実行。
