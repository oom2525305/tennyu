# 全シーンのUIと残り回数表示

能力の残り回数が画面下端へはみ出していたため、共有AbilityButtonとステージ1〜3のノーマル／ハードすべてを修正しました。

- `Assets/Project/Prefabs/UI/AbilityButton.prefab`：CountTextを96×44の固定枠へ変更。文字サイズ28、白文字、濃い背景CountBackground付き。アイコンの下に配置し、クールタイムの数字はアイコン中央へ配置。装飾と文字のRaycastはオフ。
- 全6ステージの `Canvas / GameUI / HUD / AbilityBar` を上・右へ移動。残り回数は基準解像度で画面下端から13px以上内側に収めています。能力ボタンのサイズ130×130は維持しています。
- WorldCastAreaは画面全体とし、表示中のボタン・能力アイコン・回数表示に重なる部分だけをAbilityDragButtonで配置対象外にします。以前の下側200単位を一律に除外する設定は、右下の通路を妨げたため撤廃しました。
- Title・TimelineScene・全6ステージのCanvasScalerは1280×720を基準とするScale With Screen Size、Match Heightへ統一しました。以前のConstant Pixel Size設定は置き換えています。GameScene本体にはCanvasを増やさず、生成したStage PrefabのCanvasを使用します。
- ポーズ画面の重なっていたボタン枠を250×80、中心間隔90へ調整。クリア／失敗の戻るボタンにも間隔を確保しました。失敗理由は320×90、文字20〜22で折り返します。

共有Prefabから継承するステージ1と、UIが展開されているステージ2・3の両方へ同じ変更を反映しています。既存画像・.meta・GUID・能力回数の計算処理は変更していません。Inspectorでの追加設定は不要です。

## 検証

クラウドでは800×450、960×540、1280×720、1920×1080、1024×768、2560×1080相当で回数枠が画面内に収まることを座標計算で検査しました。全6ステージの有効な能力ボタンを対象に、回数枠の余白、拡大縮小設定、共有パネルと展開済みパネルの一致を検査済みです。Prefab参照とUnityのfileID範囲の検査も通過しました。

Unityの実描画・操作は未確認です。Pull後、以下を確認してください。

1. 年表から各ステージのノーマル／ハードへ入り、画面左下で風・雷・雨・幽霊の使用可能な能力の下に「×2」などが見えること。
2. 能力を使うと回数が減り、クールタイムの数字はアイコン中央に出ること。使い切っても「×0」が残り、リトライで回数が戻ること。
3. 小さいGameビューでも回数が欠けず、ポーズ・クリア・失敗画面のボタンが重ならないこと。
4. Titleの開始案内、年表の詳細と難易度切替も同じ画面比率で確認してください。
